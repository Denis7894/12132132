# Проверка сайта кузница-контента.рф

Раз в 5 минут сайт проверяется напрямую и с узлов в Москве и Петербурге (check-host.net).
Если сайт не открывается или недоступен из России, бот заявок присылает сообщение;
когда сайт снова работает, приходит второе сообщение с длительностью сбоя. Повторов нет.
Ещё бот предупреждает об окончании сертификата безопасности (за 14, 5 и 1 день)
и раз в неделю, в понедельник после 10:00 по Москве, присылает короткую сводку.

- Код: `monitor/check.py`, расписание: `.github/workflows/monitor.yml`.
- Секрет репозитория `TG_TOKEN` — токен бота заявок.
- Получатели подписываются сами: пишут боту кодовое слово (в репозитории хранится только его отпечаток).
  Список получателей хранится в `monitor/state.json` в зашифрованном виде.
- Слово «статус» в боте — ответ о текущем состоянии в течение 5–10 минут.
- Пробное сообщение: Actions → «Проверка сайта» → Run workflow с галочкой
  или коммит в `monitor/` со словом `[пробное]` в описании.

Первый запуск с оповещениями: 22.11.2026.
